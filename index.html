Como Configurar o Firebase
1. Acesse console.firebase.google.com
2. Crie um projeto gratuito (plano Spark)
3. Ative o Realtime Database no modo de teste
4. Em "Configurações do projeto → Seus apps", copie as credenciais
5. Cole no bloco FIREBASE_CONFIG no início do arquivo HTML
